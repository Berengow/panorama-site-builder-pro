# Panorama Site Builder Pro

Профессиональный клиентский билдер для создания автономных сайтов с виртуальными 360° турами.

## Запуск

Откройте index.html или запустите локальный сервер:

```bash
python -m http.server 8080
```

Сайт полностью клиентский, использует Pannellum и JSZip с CDN.

## Экспорт

Нажмите «Экспорт сайта» — получите ZIP с готовым туром.
